The latest stable releases are **Runtime {runtimeVersion}** and **Analysis {analysisVersion}**. Runtime provides
composition, testing, tracing, and the BOM. Analysis provides optional verification and architecture graphs. The two are
independently versioned.

## Scoped execution migration

Upgrading from 0.7.0 requires API changes and recompilation. Follow the
[Runtime migration table](https://github.com/BuildMosaic/Mosaic/blob/runtime-1.0.0/docs/releases/runtime-1.0.0.md#upgrade-from-070)
and
[Analysis regeneration instructions](https://github.com/BuildMosaic/Mosaic/blob/analysis-1.0.0/docs/releases/analysis-1.0.0.md#upgrade-from-070).
