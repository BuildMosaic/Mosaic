# Homepage

Mode: Persuade. Audience: Kotlin backend engineers. Action: Get started.
The canonical brand and response-first narrative determine this surface. Use
native Astro/CSS, with real
code and geometric dependency diagrams rather than image-generated comps.

## Direction contract

THESIS: Response composition is the organizing idea. Explain shared work through
the same source code and relationships developers will use, without a feature
card catalog.

OWN-WORLD: Canonical navy, blue and orange. Flat architectural surfaces, restrained
rules, square code panels, Public Sans reading text, Barlow display, JetBrains Mono
code. Brand fragments appear once around the composition figure.

STORY: Begin at the response; launch independent branches; see where those branches
share a producer; extend to keyed work, static architecture, traces and tests;
inspect measured cost; bring an HTTP framework; start building.

FIRST VIEWPORT: A compact wide headline above two unequal columns: direct product
explanation and actions on the left, real highlighted order-page Kotlin on the
right. A dependency figure joins the code below, showing three consumers of one
OrderTile. At 390px, headline/actions lead, then the code and figure stack at a
readable scale. No interactive animation is required to understand it.

FORM: Code-and-composition narrative inside the canonical brand.
